Bake

A terminal coding agent. It is one native binary: no Node.js, no runtime to install first.

Linux (x86_64 and arm64)

curl -fsSL https://bake.justar.dev/install.sh | sh

The installer verifies the release manifest's signature and the archive's SHA-256, then installs bake under your home directory. It needs glibc 2.34 or newer. See the release manifest for the platforms published.

macOS and Windows

Support is coming in a later 0.4 release. On Windows, you can install Bake inside WSL with the Linux command above.
