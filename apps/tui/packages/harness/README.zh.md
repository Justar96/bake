# 组件预览

[English](README.md) | 中文

在仓库根目录运行 `bun run dev`，即可热重载 Ink 预览，无需 Agent、网络访问或模型密钥。`--replay` 以动画回放录制的行；`--locale zh` 选择中文。位置参数形式的夹具路径相对于 `dev.tsx` 解析；支持绝对路径和包含空格的路径。在 shell 中请为路径加引号。

开场画面会标明自己是组件预览，并提示使用 `bun run dev:tui` 进行真实对话。按 Enter 会把你的消息加入本地预览记录，并附带未连接 Agent 的提示。按 Up 可调回该消息进行编辑。预览消息只存在于内存中，不会执行命令、调用模型或修改录制内容。

当输入和输出都是 TTY 流时（包括在 CI 中），预览以交互方式渲染。调整终端大小时，输入框始终保持在终端底部；终端较矮时，其输入优先于预览提示和状态栏。Ctrl-C 会同时退出 Ink 和 Bun 的热重载监视器。

[开发指南](../../../../docs/development.zh.md#development-loops)负责构建和运行说明。[预览冒烟测试](../app/tests/dev.test.ts)在启用 CI 检测的情况下，以英文和中文检查提交、历史调回、调整大小、夹具路径和进程退出。
