Use when adding text to a screen, rewriting a confusing message, naming an action, or when asked to improve UX writing or microcopy. # UI copy

- Buttons are verbs that name the result: `Send invoice`, not `Submit`.
- Errors: what happened, then what to do. No blame, no codes alone.
- Sentence case everywhere; no exclamation marks.
